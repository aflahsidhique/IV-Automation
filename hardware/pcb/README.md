# PCB

PCB design files for the sensor/controller board — the ESP32-C3
SuperMini, IR LED/phototransistor circuit (220 Ω / 10 kΩ), OLED header,
servo and buzzer connections, and the power section described in
[docs/design.md](../../docs/design.md#hardware).

No PCB layout exists yet; the current prototype is built on
breadboard/perfboard per the [pin assignment](../../docs/design.md#suggested-esp32-c3-pin-assignment).
Add schematic/layout sources (e.g. KiCad) here once a board is designed.
