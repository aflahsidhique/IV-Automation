# Mechanical

Mechanical design files for the external, non-sterile tube clamp and
sensor housing.

- [`clip_case.stl`](clip_case.stl) — 3D-printable clip/case for mounting
  the sensor and clamp assembly around the drip tubing.

The servo-driven clamp operates on the outside of the tubing only — it
must never enter the fluid path or damage the sterile tubing. See
[docs/design.md](../../docs/design.md#servo-clamp) for the clamp operating
principle and [`diagrams/mechanical-clamp.png`](../../diagrams/mechanical-clamp.png)
for the assembly diagram.
